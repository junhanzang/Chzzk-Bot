# 치지직 데스크 · Chrome 확장

공식 치지직 Chrome 탭을 A–D 네 자리로 관리하고, 듣는 방송을 바꾸는 사이드 패널입니다. **앱 없이도 즐겨찾기·시청 모음·방송 탭 열기·소리 전환·창 배치·통나무 자동 수령을 사용할 수 있습니다.** 데스크톱 앱을 연결하면 구간 보관과 클립 보관함도 사용할 수 있습니다.

## 개발 버전 설치

[GitHub Releases](https://github.com/junhanzang/Chzzk-Bot/releases)의 `desk-v` 버전에서 `chzzk-desk-chrome-<버전>.zip`을 받았다면 먼저 압축을 풀고, 아래 3번에서 압축을 푼 폴더를 선택합니다. 소스 코드 전체를 받을 필요는 없습니다. [빌드·배포 안내](../docs/RELEASING.md)

프로젝트 루트의 **`setup-chrome.cmd`**를 더블클릭하면 Chrome 확장 관리 화면을 열고 설치 폴더 경로를 클립보드에 복사합니다. 기존 클립보드 내용은 바뀝니다. 아래 등록 절차는 Chrome에서 직접 완료하세요. 스크립트는 브라우저 설정이나 프로필을 수정하지 않습니다. 화면과 클립보드를 건드리지 않고 안내만 출력하려면 `setup-chrome.cmd --print-only`를 사용합니다.

1. Chrome에서 `chrome://extensions`를 엽니다.
2. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
3. 이 저장소의 `browser-extension` 폴더를 선택합니다.
4. 도구 모음의 치지직 데스크 확장 아이콘으로 사이드 패널을 엽니다.

코드를 수정한 뒤에는 확장 관리 화면에서 새로고침하고 패널을 다시 엽니다. **통나무 스크립트도 갱신하려면 기존 치지직 방송 탭을 F5로 새로고침하세요.** 0.3.0에는 즐겨찾기·클립 검색과 저장 길이 선택을 추가했습니다. Chrome에서 추가 사이트 접근을 안내하면 `api.chzzk.naver.com`이 보유량 조회 대상입니다. 아직 Chrome 웹 스토어 배포본은 아닙니다.

## Chrome에서 사용

- 방송 URL 또는 32자리 채널 ID를 즐겨찾기에 추가하고 **A / B / C / D**를 누릅니다.
- 방송은 공식 치지직 페이지의 Chrome 탭으로 열립니다. **방송 열기**는 해당 탭으로 이동하며 닫힌 탭은 다시 엽니다.
- 각 자리의 **듣기**로 듣는 방송을 선택하고 **전체 음소거**로 모두 끕니다. 공식 플레이어 자체가 음소거 상태라면 플레이어에서도 소리를 켜야 합니다.
- **나란히 / 세로 / 4분할 / 메인 크게**와 메인 방송을 선택한 뒤 **창 배치**를 누르면 최대 네 공식 방송 탭을 별도 Chrome 창으로 배치합니다. 처음에는 충분히 넓힌 일반 Chrome 창에서 사용하세요. 메인 변경은 듣는 방송을 바꾸지 않으며 배치와 메인 선택은 저장됩니다.
- 패널에서 현재 배정과 방송 탭 상태를 확인합니다. 즐겨찾기 삭제와 자리 비우기는 각 항목의 `×` 버튼으로 실행합니다.
- 즐겨찾기는 이름·채널 ID로 검색합니다. 입력한 검색어는 상태 갱신 중에도 유지합니다.
- 즐겨찾기 이름을 수정하고 자주 보는 채널을 위에 고정합니다. **시청 모음**은 현재 A–D 배치와 메인 방송을 최대 10개 저장합니다. 불러오기 전에 바뀌는 자리를 안내하고 공식 방송 창을 배치합니다. 소리와 보관을 새로 켜지 않으며, 바뀌는 자리의 기존 구간 보관은 종료됩니다.
- 독립 모드의 시청 모음은 Chrome에 저장합니다. 앱 연결 중에는 앱의 모음을 공유하며 두 모음 목록을 자동 병합하지 않습니다. [0.5.0 변경 내용](../docs/releases/0.5.0.md)

Chrome의 공식 플레이어를 사용하므로 고화질 시청에 필요한 치지직의 공식 확장·환경·계정 조건은 그대로 적용됩니다. 이 확장이 고화질 지원 조건을 대체하지 않으며, 1080p 재생 검증을 완료했다는 의미도 아닙니다.

Chrome 멀티뷰는 공식 방송 탭을 여러 창에 배치하는 방식입니다. 이미 분리한 방송 창은 재사용하며, 다른 탭이 함께 있는 창은 통째로 옮기지 않습니다. 한 창 안에 네 영상을 넣는 방식은 데스크톱 앱에서 제공합니다.

## 통나무 자동 수령과 보유량

**통나무 자동 수령**은 기본적으로 꺼져 있습니다. 켜면 이 확장에서 A–D로 관리하는 방송의 시청 보상 버튼을 감지해 수령합니다. 자동 수령 설정은 저장하며, 설정을 꺼도 보유량은 약 60초 간격으로 조회합니다. 보상 상태와 보유량 변화를 확인한 뒤 수령 완료를 표시하고, 조회 실패를 보유량 0으로 처리하지 않습니다.

Chrome의 로그인 상태를 사용하며 앱의 로그인·자동 수령 설정·보유량과는 별개입니다. 관리하지 않는 방송 탭에는 자동 수령을 적용하지 않습니다. 다른 자동 수령 확장을 사용한다면 중복 실행을 피하도록 한쪽만 켜세요.

여러 방송을 열어도 한 채널의 시청 시간만 인정됩니다. 1시간 시청 보상은 버튼이 생긴 뒤 1시간 내 수령해야 합니다. [네이버 통나무 안내](https://help.naver.com/service/30044/contents/24337?lang=ko&osType=COMMONOS)

채팅 영역을 접어 보상 버튼이 없거나 치지직의 화면·응답 구조가 바뀌면 자동 수령이 동작하지 않을 수 있습니다. 현재 가짜 화면·응답 테스트를 통과했으며 실제 계정 수령은 사용자 확인이 필요합니다. [구현 근거와 범위](shared/REWARDS-SOURCES.md)

## 앱 연결과 저장

0.4.0에서는 앱 연결 후 각 슬롯의 **자동 저장**에서 키워드·채팅 급증 감지도 설정할 수 있습니다. **최근 구간 보관**을 켜고 해당 공식 방송 탭의 채팅을 열어 두세요. 앞 약 20초·뒤 약 10초를 앱이 로컬 MP4로 저장하며, Chrome만 단독 실행할 때에는 사용할 수 없습니다. 기본 꺼짐, 채널당 2분 간격·시간당 최대 10회 시도입니다. 패널을 닫아도 관리하는 방송 탭이 열려 있으면 감지는 계속됩니다. [조건과 제한 사항](../docs/releases/0.4.0.md)

1. [데스크톱 앱](../desktop/README.md)을 실행합니다.
2. 앱에서 **연결 코드 복사**를 누릅니다.
3. 확장 패널의 **데스크톱 앱 연결**을 펼쳐 복사한 연결 코드를 붙여넣고 **앱 연결**을 누릅니다.
4. 방송의 **최근 구간 보관**을 직접 켜고 저장 길이를 **15·30·60초** 중 선택합니다(기본 30초). 완료된 영상이 최소 4초 쌓이면 저장할 수 있으며, 선택한 길이보다 적게 모였다면 확보된 분량만 저장합니다. 앱 연결 중에는 앱과 저장 길이를 공유합니다.
5. 클립 보관함에서 파일을 열거나 **폴더 열기**로 전체 저장 파일을 확인합니다. 방송 이름·제목·파일명으로 전체 인덱스를 검색하고 50개씩 **더 보기**로 이어 봅니다. 제목 수정·별표·저장 유형 필터와 정렬을 사용할 수 있으며 개별 **폴더** 버튼은 탐색기에서 해당 파일을 선택합니다. 제목 수정은 MP4 파일명을 바꾸지 않습니다.

**전체 보관 켜기·끄기**는 Chrome 시청 모드의 자리에만 적용합니다. 시작하려면 해당 관리 탭이 열려 있어야 하며, 일부 실패하면 성공 수와 실패한 자리를 안내합니다. 다른 자리에서 앱으로 시청 중인 방송은 이 명령의 대상에 포함하지 않습니다.

**Chrome 로그인과 앱 로그인은 서로 별개입니다.** 시청은 Chrome의 네이버 로그인 상태를 사용하고, 구간 보관은 앱의 로그인 세션을 사용합니다. 저장 권한 안내가 나타나면 앱에서 네이버 로그인 상태를 확인하세요. 연결 코드를 통한 앱 연결 자체가 네이버 로그인을 대신하지는 않습니다.

보관은 켠 시점 이후부터 시작하며 저장 길이는 영상 구간 경계와 확보된 분량에 따라 달라집니다. 보관을 끄면 임시 영상이 삭제됩니다. 방송 연결이 끊겨도 완료된 영상이 4초 이상 남아 있으면 마지막 장면을 저장할 수 있습니다. 저장 방식과 제한은 [앱 문서](../desktop/README.md)를 참고하세요.

앱에 응답이 없으면 패널에 **앱 응답 없음**을 표시합니다. 앱을 다시 실행하거나 **연결 해제 · 독립 모드로**를 눌러 Chrome 기능을 사용할 수 있습니다.

앱을 다시 시작하거나 **연결 초기화**를 누르면 이전 연결 코드는 만료됩니다. 앱에서 새 코드를 복사해 다시 연결하세요. 앱 연결이 끊겨도 이미 열려 있는 Chrome 탭의 소리 전환과 전체 음소거는 사용할 수 있습니다. Chrome 탭을 닫거나 확장 연결을 해제해도 앱에서 켠 구간 보관은 계속됩니다. 보관을 끝내려면 앱에서 끄거나 앱을 종료하세요.

## 단축키

| 기능 | 기본 단축키 |
| --- | --- |
| A 방송 듣기 | `Alt+Shift+1` |
| B 방송 듣기 | `Alt+Shift+2` |
| 전체 음소거 | `Alt+Shift+M` |
| 선택한 길이의 최근 구간 저장 | `Ctrl+Shift+S` |

저장은 앱 연결과 구간 보관이 준비되어야 합니다. 단축키도 선택한 15·30·60초 길이를 사용합니다. 듣는 방송을 저장하며, 전체 음소거 상태에서는 선택한 메인 방송을 대상으로 합니다(초기값 A). Chrome의 `chrome://extensions/shortcuts`에서 단축키를 확인하거나 변경할 수 있습니다. 다른 확장 또는 운영체제와 겹치면 기본 단축키가 등록되지 않을 수 있습니다.

## 수동 확인 순서

아래는 사용자가 확인할 절차이며, 실제 Chrome 조작 또는 고화질 시청 검증을 완료했다는 기록이 아닙니다.

1. 앱을 연결하지 않고 채널을 추가한 뒤 A–D 공식 탭이 열리는지 확인합니다.
2. 각 방송 듣기 → 전체 음소거로 소리가 전환되는지 확인합니다. 네 가지 배치와 메인 선택 후 **창 배치**를 누르고, 다시 눌러도 창이 계속 작아지지 않는지 확인합니다. 탭을 닫은 뒤 **방송 열기**로 다시 열어 봅니다.
3. 채널 입력 중 패널 상태가 갱신되어도 URL·이름이 유지되는지 확인합니다. Tab 키로 이동하며 각 입력과 버튼의 포커스를 확인합니다.
4. 앱 연결 코드 입력 후 **앱 연결됨**이 표시되는지 확인합니다. 잘못된 코드는 오류로 안내되는지 확인합니다.
5. 앱 로그인 안내를 확인하고, 직접 구간 보관을 켠 뒤 저장 버튼이 충분한 영상이 쌓인 후 활성화되는지 확인합니다.
6. 저장한 클립과 보관 폴더를 열어 봅니다. 앱을 종료한 뒤 응답 없음 표시와 연결 해제가 동작하는지 확인합니다.
7. 방송 탭을 새로고침하고 로그인 후 통나무 보유량을 확인합니다. 자동 수령을 켜고 실제 시청 보상이 나타날 때 수령·보유량 증가가 표시되는지 확인합니다. 자동 수령을 끄면 다음 보상은 직접 받을 수 있어야 합니다.
8. 즐겨찾기·클립 검색 중 상태 갱신이 되어도 검색어가 유지되는지 확인합니다. 저장 길이를 바꾸고 버튼·단축키 저장에 선택값이 적용되는지 확인합니다.

패널은 보이는 동안 약 2초 간격으로 상태를 갱신하며, 실행 중인 요청을 겹쳐 보내지 않습니다. 채널명·클립명·오류 메시지는 HTML로 해석하지 않고 텍스트로 표시합니다.

개발 시 `npm run check`로 앱·확장 문법과 자동 테스트를 함께 실행할 수 있습니다. 실제 Chrome을 열지 않습니다. [유지보수 구조와 모듈별 책임](../desktop/ARCHITECTURE.md)
