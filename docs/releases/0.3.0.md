# Chzzk Desk 0.3.0

치지직 시청용 Windows 앱과 Chrome 확장의 첫 GitHub 배포입니다. 기존 Python 봇과 별도로 실행됩니다.

- A–D 네 방송, 화면 배치·메인 방송·듣는 방송 선택
- 즐겨찾기·클립 검색, 최근 15·30·60초 MP4 저장
- 네이버 웹 로그인, Chrome 공식 탭 시청과 앱의 녹화 연결
- 통나무 보유량 표시와 선택적으로 켜는 자동 수령
- 플레이어·녹화·저장소·연결·화면 코드의 모듈 분리

## 다운로드와 실행

- `Chzzk-Desk-0.3.0-Setup-x64.exe`: Windows x64 설치 프로그램
- `Chzzk-Desk-0.3.0-win-x64.zip`: 모두 압축 해제한 뒤 `Chzzk Desk.exe` 실행
- `chzzk-desk-chrome-0.3.0.zip`: 압축 해제 후 `chrome://extensions`에서 개발자 모드 → 압축해제된 확장 프로그램 로드
- `SHA256SUMS.txt`: 세 배포 파일의 SHA-256

앱 배포 파일에는 Electron과 FFmpeg가 들어 있어 Node.js나 Python을 따로 설치하지 않아도 됩니다. Chrome 확장 ZIP은 Chrome 웹 스토어 배포본이 아닙니다. 앱에서 연결 코드를 복사해 확장에 입력하면 Chrome으로 시청하면서 앱에 클립을 저장할 수 있습니다. 앱 로그인과 Chrome 로그인은 별개입니다.

## 현재 범위

이 버전은 시험 배포(prerelease)입니다. 코드서명 인증서를 적용하지 않아 Windows에서 게시자 확인 경고가 나올 수 있습니다. 앱 내부 고화질 재생은 지원하지 않으며, 고화질은 기존 Chrome 공식 재생 환경을 사용합니다. 자동 업데이트는 없으므로 다음 버전도 Releases에서 내려받습니다.

자동 검사는 실제 계정을 사용하지 않습니다. 실제 방송의 화질·로그인·통나무 수령과 설치된 앱의 화면은 별도 확인이 필요합니다. 기존 설정과 클립은 배포 파일에 포함하지 않습니다.

배포 준비 중 JavaScript 80개 파일의 문법 검사, 앱·확장 테스트 182개, 기존 Python core 테스트 76개가 통과했습니다. 실제 Windows 설치 파일·ZIP 생성과 ASAR의 35개 앱 파일·공통 모듈 경로·FFmpeg 포함 검사를 통과했고, Chrome ZIP은 25개 항목의 원본 일치를 별도 ZIP 리더로 확인했습니다. 설치 파일과 실제 앱 화면은 실행하지 않았습니다.
