# Chzzk Desk 0.8.0

팔로잉·즐겨찾기 목록을 관심 게임·카테고리와 실제 이용 기록에 따라 정렬합니다. 기본 정렬은 **추천순**이며 **자주 보는 순 / 방송 중 우선 / 이름순**도 선택할 수 있습니다. 직접 고정한 방송을 먼저 두고, 각 그룹에서는 방송 중인 채널을 먼저 보여줍니다.

추천순은 치지직에서 팔로우한 게임·카테고리와 방송의 현재 카테고리를 비교하고, 이 앱·확장에서 직접 연 방송·재생 시간·채팅 참여를 반영합니다. 목록에는 추천 이유를 최대 세 개 표시합니다. 카테고리 조회가 실패해도 방송 목록과 로컬 이용 기록 정렬은 유지합니다.

이용 기록은 기능을 적용한 이후부터 이 환경에서 쌓입니다. 치지직의 과거 전체 시청 기록·채팅 내역은 가져오지 않습니다. 앱과 Chrome은 각 기기의 프로필에 별도로 기록하며 앱 연결 RPC로 내보내지 않습니다. 앱을 다시 열어도 기록과 정렬 선택은 유지합니다.

- 방문은 같은 채널에 10분 안에 반복해서 눌러도 한 번만 반영합니다. 자동 복원은 방문으로 세지 않습니다.
- 시청은 관리 중인 공식 플레이어의 실제 재생 진행으로 집계합니다. 일시정지·버퍼링·탐색·오래 멈춘 관측은 제외합니다. 여러 방송이 실제 재생되면 각각 집계하며 사용자가 화면을 주시했는지를 판단하지는 않습니다.
- 채팅 참여는 공식 채팅 입력창의 직접 입력 활동을 채널당 30초에 한 번 반영합니다. 전송 성공 횟수는 아닙니다. 다른 사람의 채팅이나 스크립트가 발생시킨 DOM 입력은 세지 않고, 채팅 내용·닉네임·입력 내용은 읽거나 저장하지 않습니다. 직접 연 채팅 팝업도 포함합니다.
- 최근 이용 신호는 14일 반감기로 약해집니다. 누적 통계·감쇠 통계만 저장하며 같은 방송의 중복 창으로 점수를 부풀리지 않도록 상한을 둡니다.
- **추천 기준 · 내 기록 → 추천 기록 초기화 → 기록 삭제 확인**으로 로컬 기록을 지웁니다. 즐겨찾기와 치지직 팔로우는 유지합니다.

앱을 완전히 종료한 뒤 `start-desk.cmd`로 다시 실행합니다. 실행 중에 런처를 누르면 기존 창만 앞으로 가져옵니다. Chrome은 확장 관리에서 새로고침하고 패널을 다시 연 뒤 기존 방송·채팅 팝업도 F5로 새로고침합니다. 확장 새로고침 시 관리 중인 창의 세션 연결이 초기화되므로 패널에서 방송을 A–D 자리에 다시 열고, 별도 채팅은 **채팅 새 창**을 다시 눌러 활동 집계 대상을 연결합니다. 즐겨찾기와 추천 기록은 유지됩니다. 실제 계정·화면 조작 없이 가짜 DOM·세션 응답·브라우저 API로 검증합니다. [카테고리 조회 근거](../../browser-extension/shared/FOLLOWING-SOURCES.md). 공개 릴리스는 별도 `desk-v0.8.0` 태그가 필요합니다.

검사 중 발견한 간헐적인 로컬 연결 실패도 수정했습니다. OS가 fetch에서 차단한 포트를 배정하면 영상·확장 연결 서버가 최대 8회 재선택하며 외부 인터페이스를 열지 않습니다.

2026-11-06 로컬 검증: JavaScript 146개 파일 문법, 데스크톱 204개와 확장·공유 UI 242개 테스트 통과. 합성 영상의 수동 클립 32.023초·자동 클립 30.023초 영상·음성 디코딩, Windows 설치 파일·ZIP과 Chrome 확장 ZIP 생성 및 포함 파일 검사도 통과했습니다. 실제 로그인한 계정의 카테고리 조회와 화면 내 활동 감지는 사용자 확인이 필요합니다.
