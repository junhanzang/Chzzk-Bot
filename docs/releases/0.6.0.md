# Chzzk Desk 0.6.0

시청은 Chrome 공식 방송 탭에서 하고, 옆 패널에서 자주 쓰는 조작을 처리하는 흐름으로 정리했습니다. 앱에는 클립 관리·봇 제어·AI 연결 설정을 모았습니다.

## 화면과 사용 흐름

- Chrome 패널: 시청 / 클립 / 봇 탭. 앱을 연결하지 않아도 기존 방송 열기·듣기·배치 기능을 사용할 수 있습니다.
- 데스크톱 앱: 시청 / 클립 / 봇 / 설정 화면. 탭을 바꿔도 방송 재생과 구간 보관은 유지하고, 보이지 않는 네이티브 플레이어는 화면을 덮지 않습니다.
- 기존 즐겨찾기·시청 모음·자동 클립·통나무·클립 검색과 편집 기능을 유지합니다.
- 봇 화면에서 대상 방송과 실행 방식을 고르고 시작·중지합니다. 기본값은 실제 채팅을 보내지 않는 미리보기입니다. 승인 모드에서는 답변을 수정하거나 넘길 수 있으며, 만료된 제안은 전송하지 않습니다.
- 앱에서 로그인한 네이버 세션을 봇의 승인/자동 전송에도 사용합니다. 쿠키는 메인 프로세스에서 Python으로만 전달하고 확장이나 UI 상태에는 반환하지 않습니다. Chrome 로그인과 앱 로그인은 계속 별개입니다.
- 최근 들은 말·제안·생략·필터·오류·전송 상태를 최대 50개 보여줍니다. 문장 미리보기는 직접 넣은 발화와 앞뒤 맥락만 평가하며 음성 장치를 열지 않습니다.

## AI 연결과 설치

앱 설정에서 Ollama 또는 OpenAI 호환 Chat Completions API를 선택합니다. 외부 AI는 Ollama 설치 없이 사용하며, 제공업체의 기본 URL·모델 식별자·API 키를 직접 입력합니다. 기본 URL에 `/chat/completions`는 붙이지 않습니다. `max_completion_tokens`와 일반 텍스트 Chat Completions 응답을 지원하는 서비스가 필요합니다. 설정 저장 자체는 실제 연결 성공이나 모델 품질 검증을 뜻하지 않습니다.

외부 AI에는 발화·최근 채팅·기억 문맥을 전송하고, 응답 생성과 기억 요약에 서비스별 사용료가 발생할 수 있습니다. API 키는 데스크톱 앱에서만 입력하며 가능한 환경에서는 운영체제 기능으로 암호화해 저장합니다. 암호화가 불가능하면 키는 세션에만 유지합니다. 제공자나 서버 주소를 바꾸면 기존 키를 자동 재사용하지 않습니다.

앱 패키지는 봇 소스도 포함합니다. Python 3.11 이상과 봇 패키지는 별도로 필요하며 앱이 자동 설치하지 않습니다. 단순 시청·클립 기능은 Python 없이 사용합니다. 실시간으로 방송을 듣는 AI/하이브리드 모드는 외부 AI를 사용해도 음성 인식 패키지·모델·출력 장치가 필요합니다. 문장 미리보기에는 음성 인식 환경이 필요하지 않습니다.

## 검증 범위와 배포

자동 검사는 가짜 모델·장치·계정·DOM을 사용해 명령 경계, 승인 만료, 중지 경합, 오류 분류, 키 저장·비공개 상태, 화면 전환과 입력 보존을 확인합니다. 소스 포함 목록과 패키지 상대 경로도 검사합니다. 실제 Chrome/Electron 화면 조작, 실제 AI 품질, 실제 계정 전송은 별도 확인이 필요합니다.

2026-11-05 로컬 검증: Python 579개, JavaScript 118개 파일 문법과 데스크톱 163개·확장/공통 UI 143개 테스트 통과. 실제 Node→Python 상태 조회·중지 통신과 모델 없는 데모, RPC를 거친 합성 방송 MP4의 영상·음성 디코딩(30초 요청, 실제 32.023초), Windows 설치 파일·ZIP과 Chrome 확장 패키징을 확인했습니다. 실제 앱·브라우저 창은 실행하지 않았습니다.
