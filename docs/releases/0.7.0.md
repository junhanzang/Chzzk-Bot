# Chzzk Desk 0.7.0

자주 보는 방송을 고정하고, 로그인한 계정의 팔로잉 목록에서 찾아 시청하는 흐름을 추가했습니다. 앱과 Chrome에서 여러 방송 소리와 별도 채팅 창을 사용할 수 있습니다.

- 앱 로그인 후 **내 팔로잉 방송**을 자동 조회합니다. Chrome 패널은 Chrome의 로그인으로 별도 조회하며, 패널 사용 중 주기적으로 갱신하고 치지직 로그인 후 페이지로 돌아왔을 때 다시 확인합니다.
- 방송 중인 채널부터 표시하고 검색·더 보기·새로고침을 제공합니다. **☆ 고정**은 해당 채널만 즐겨찾기에 저장하며 방송을 자동 재생하지 않습니다. 기존 별명을 유지하며 고정한 채널은 재실행해도 남습니다. Chrome에는 즐겨찾기 서랍을 열지 않아도 보이는 고정 목록과 A–D 버튼을 제공합니다.
- 방송별 **소리 켜기 / 끄기**로 두 개 이상, 최대 네 방송을 함께 듣습니다. 숫자 단축키는 기존처럼 한 방송만 켜고 전체 음소거는 모두 끕니다. 클립 저장 단축키는 켜져 있는 소리 중 마지막으로 켠 방송을 대상으로 합니다.
- **채팅 새 창**은 공식 채팅 전용 페이지를 크기 조절 가능한 창으로 엽니다. 같은 방송의 창은 재사용합니다. 재생·녹화·다른 탭의 소리를 변경하지 않습니다.

팔로잉 데이터는 읽기 전용 계정 조회 결과이며 자동으로 디스크에 저장하지 않습니다. 로그아웃·계정 확인·조회 실패 시 이전 목록을 비웁니다. 직접 저장한 즐겨찾기는 계정 목록과 별개로 유지합니다. 앱과 Chrome의 로그인 및 소리 선택은 각 시청 환경에서 따로 관리합니다.

채팅 창 분리는 방송 페이지 안의 채팅을 자동으로 접지 않습니다. 자동 클립과 통나무 감지는 기존 방송 페이지에서 계속 동작합니다. 소리를 켰는데 들리지 않으면 공식 플레이어 자체의 음소거도 확인하세요. 앱을 새로 시작하면 소리는 꺼진 상태이며, Chrome 서비스 워커가 다시 깨어날 때는 살아 있는 관리 탭의 소리 선택만 복원합니다.

검증은 가짜 DOM·계정 응답·Electron/Chrome API를 사용합니다. 실제 계정의 팔로잉 조회와 공식 채팅 화면은 사용자 확인이 필요합니다. [팔로잉 조회 근거](../../browser-extension/shared/FOLLOWING-SOURCES.md). 공개 릴리스는 별도 `desk-v0.7.0` 태그가 필요하며 main CI는 Windows 앱과 확장 패키지를 Actions 산출물로 만듭니다.
