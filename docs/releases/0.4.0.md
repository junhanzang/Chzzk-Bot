# Chzzk Desk 0.4.0

채널별 자동 로컬 클립과 녹화 코드 모듈화를 추가한 시험 버전입니다.

- 앱과 앱에 연결한 Chrome에서 각 방송의 **자동 저장**을 펼쳐 키워드 또는 채팅 급증 감지를 설정합니다. 기본은 꺼짐입니다.
- **최근 구간 보관**을 켜고 공식 채팅을 열어 두면 새 채팅에서 조건을 감지합니다. 키워드는 최대 10개·각 40자이며 대소문자를 구분하지 않는 부분 일치입니다. 처음 5초는 수집만 합니다.
- 채팅 급증은 35초간 기준을 수집한 뒤, 최근 5초에 새 메시지 15개 이상이면서 직전 30초 평균의 3배 이상일 때 감지합니다. 인기 채널이나 반복 채팅에서 오탐이 있을 수 있습니다.
- 감지 당시 완료된 영상 끝을 기준으로 앞 20초·뒤 10초를 MP4로 저장합니다. 영상 구간 경계 때문에 실제 길이는 조금 늘어날 수 있고, 시청 화면·채팅·녹화 스트림 지연은 서로 달라 정확한 장면 일치는 보장하지 않습니다.
- 채널당 2분 간격, 한 시간에 최대 10회 시도합니다. 수동 저장이 진행 중이면 자동 저장은 기다리거나 건너뜁니다. 45초 안에 필요한 영상을 확보하지 못하거나 녹화·채널·설정이 바뀌면 대기 작업을 버립니다.
- 자동 저장을 꺼도 이미 파일 내보내기를 시작한 작업은 완료합니다. 대기 중인 후보와 이후 감지만 중지합니다.
- 보관함에 **자동 · 키워드**, **자동 · 채팅 급증** 배지가 표시됩니다. 채팅 본문과 작성자는 저장 파일·인덱스에 기록하지 않습니다.
- 녹화 세션, 세그먼트 보관·선택, MP4 내보내기, 클립 인덱스, 채팅 관찰, 자동 저장 스케줄러를 각각 독립 모듈로 분리했습니다.

Chrome만 단독 실행한 상태에서는 자동 저장을 사용할 수 없습니다. 앱 연결과 앱의 녹화 로그인이 필요합니다. 자동 저장 설정은 복원하지만 앱 재시작 시 구간 보관은 자동으로 시작하지 않습니다. 이 기능은 치지직 서비스에 클립을 게시하지 않습니다.

치지직 페이지의 채팅 DOM이 바뀌거나 채팅이 로드되지 않으면 감지가 멈출 수 있습니다. [선택자 확인에 참고한 프로젝트](https://github.com/lirpa62/Chzzk-Platter/blob/main/src/content.js)의 DOM 구조를 참고했으며 구현 코드를 복사하지 않았습니다. 실제 계정·방송 화면 검증은 수행하지 않았고, 가짜 DOM·플랫폼 객체와 합성 영상으로 검증합니다. CI에도 자동 감지부터 MP4 영상·음성 디코딩까지 확인하는 검사를 추가했습니다.

2026-10-02 로컬 검증: JavaScript 95개 파일 문법 검사, 데스크톱 122개·확장 및 공통 UI 102개 테스트, 기존 Python 76개 테스트가 통과했습니다. 합성 영상으로 자동 저장 30.023초·수동 RPC 저장 32.023초 MP4의 영상과 음성을 끝까지 디코딩했습니다. Windows 패키지의 43개 앱 파일·상대 참조·FFmpeg 포함과 Chrome ZIP의 28개 실행 파일 및 LICENSE를 검사했습니다.

기존 클립·로그인 데이터는 유지됩니다. Windows 설치 파일·ZIP과 Chrome ZIP의 패키징 방식은 0.3.0과 같습니다. 코드서명·자동 업데이트·앱 내부 고화질 지원은 포함하지 않습니다.
