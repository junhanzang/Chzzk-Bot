# Chzzk Desk 0.5.0

멀티뷰를 다시 준비하는 시간과 저장한 클립을 찾는 수고를 줄이는 시험 버전입니다. 앱과 Chrome 확장에 같은 편의 기능을 제공합니다.

- **시청 모음**: 방송 A–D, 화면 배치, 메인 방송을 이름 붙여 최대 10개 저장합니다. 불러오기 전에 바뀌는 자리와 종료되는 구간 보관을 확인할 수 있습니다. 같은 채널·시청 방식인 자리는 보관을 유지하며, 바뀐 자리에서는 소리와 녹화를 새로 켜지 않습니다.
- **즐겨찾기 정리**: 표시 이름을 수정하고 자주 보는 채널을 목록 위에 고정합니다. 채널 ID와 기존 클립 파일에는 영향을 주지 않습니다.
- **전체 보관 켜기·끄기**: 여러 방송의 최근 구간 보관을 한 번에 조절합니다. 일부 방송만 실패하면 성공 수와 실패한 자리를 표시합니다. Chrome에서는 Chrome 시청 모드의 자리만 대상으로 합니다.
- **클립 관리**: 보관함 제목 수정, 별표 즐겨찾기, 직접·자동 저장 및 감지 유형별 필터, 최신순·오래된순 정렬을 지원합니다. 제목을 바꿔도 실제 MP4 파일명은 유지됩니다.
- **전체 클립 검색**: 최신 100개 제한을 없애고 저장된 인덱스 전체에서 방송 이름·제목·파일명을 찾습니다. 한 번에 50개씩 표시하며 **더 보기**로 이어 볼 수 있습니다. 새 클립 저장이나 편집 중 서로 다른 목록 버전의 페이지를 섞지 않습니다.
- **폴더에서 보기**: 개별 클립의 **폴더** 버튼은 실제 파일 위치를 확인한 뒤 탐색기에서 해당 파일을 선택합니다. 보관 폴더 전체를 여는 기존 버튼도 유지됩니다.
- **단축키 안내**: 앱과 Chrome 패널 안에서 각 환경의 단축키를 확인합니다.

Chrome만 사용할 때에는 즐겨찾기와 시청 모음을 확장에 저장합니다. 앱에 연결하면 앱의 즐겨찾기·시청 모음·클립 보관함을 공유합니다. 독립 모드의 시청 모음과 앱의 시청 모음은 별개이며 자동 병합하지 않습니다. 클립 관리와 구간 보관은 앱 연결이 필요합니다.

시청 모음은 로그인·소리·구간 보관·자동 저장 설정을 저장하지 않습니다. 채널별 자동 저장 설정은 기존대로 별도 유지됩니다. 시청 모음을 앱에서 불러오면 앱 플레이어로, Chrome에서 불러오면 공식 Chrome 방송 창으로 엽니다. 고화질 조건과 자동 클립의 제한은 이전 버전과 같습니다.

즐겨찾기 편집·시청 모음·클립 목록은 공통 UI 모듈로 분리하고, 파일 조회·메타데이터 변경과 플랫폼별 방송 전환은 각 서비스가 담당합니다. 자동 테스트는 가짜 DOM·플랫폼 객체와 합성 영상을 사용합니다. 실제 Electron·Chrome 화면, 계정 및 방송은 대신 조작하지 않았습니다.
